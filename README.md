# Games 🎮

A collection of HTML games and creations designed to work with
clever—or ugly!—3D-printed accessories for your screen.

## Download and play

1. Click **Code → Download ZIP**.
2. Extract the ZIP file.
3. Open the HTML file of the game you want to play in your browser.

Keep any accompanying images, CSS, and JavaScript files in their
original folders so the games work correctly.

## Share your creations

Have a new game or an idea for a 3D-printed screen accessory?

Visit the separate sandbox repository to submit your creation
through a pull request. Submissions are reviewed before being added.

Please submit only content you created or have permission to share,
and describe any requirements needed to run it.
