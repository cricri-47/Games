Hors connexion

Relier les deux joueurs

Sur le même réseau local : le joueur 1 crée une invitation, le joueur 2 la colle et crée une réponse. Le joueur 1 colle ensuite cette réponse pour connecter la partie.

Connexion directe uniquement : aucun serveur, service externe ou bibliothèque téléchargée. Les deux appareils doivent pouvoir communiquer sur le réseau. Ne désactivez pas le pare-feu ; si Windows le demande, autorisez le navigateur uniquement sur votre réseau privé de confiance.
